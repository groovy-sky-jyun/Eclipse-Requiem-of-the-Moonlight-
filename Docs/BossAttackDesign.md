# 보스 공격 기획서 — 거문고 혈귀

## 1. 컨셉

조선을 배경으로 한 흡혈귀 보스. 무기이자 정체성은 **거문고 하나**다.

거문고는 6현을 **술대(대나무 막대)로 내려치는** 악기로, 손가락으로 뜯는 가야금과 달리 굵고 묵직한 타격음을 낸다. 원래부터 타악기에 가까워 굉음 연출과 맞물린다.

**역설 연출**이 이 보스의 핵심이다. 예열 구간의 악구는 정악(正樂)풍으로 느리고 정갈하다. 피해가 들어가는 순간에만 현이 끊어지는 파열음과 불협화음이 끼어든다. 아름다움이 깨지는 순간이 곧 공격 순간이다.

## 2. 공통 규칙

### 2-1. 연주는 예열의 일부다

보스는 평소 술대를 내리고 있다. **공격에 들어갈 때만** 현에 얹고 짧은 악구를 켠다. 악구가 스킬마다 다르므로 플레이어는 **첫 음만 듣고 어떤 공격인지 판단**할 수 있다.

### 2-2. 세 기본기는 "그 연주가 어떻게 되는가"로 갈린다

| 스킬 | 연주의 운명 | 발동 신호 |
| --- | --- | --- |
| 단현 | **끊긴다** | 소리가 사라짐 |
| 실음 | **어긋난다** | 틀린 음 하나 |
| 공명 | **울린다** | 저주파가 계속 이어짐 |

### 2-3. 상태 머신과 그로기 (기존 규칙 유지)

`Idle -> Startup -> Active -> Recovery -> Idle`

- Startup 중 플레이어 필살기: 공격을 취소하고 즉시 그로기 진입
- 그 외 단계: 스태거만 누적
- 스태거 충족: Startup / Active 중에는 대기, Recovery 또는 Idle에서 그로기 진입
- 스태거 충족 순간, 발동이 늦어도 피드백(연출·사운드)은 즉시 준다

## 4. 단현 (斷絃) — 무음 참격 3연

`UBossAttack_SilentSlash`

> 연주를 끊고, 정적 뒤에 반달 참격을 **연속 3회** 날린다.
> 정적은 한 번뿐이며, 참격 3회가 그 뒤에 이어진다.

### 타임라인

| 상태 | 시간 | 연출 |
| --- | --- | --- |
| Startup · 연주 | 0.6s | 거문고를 세워 안고 술대를 현에 얹음. **낮고 느린 3음.** 발밑에서 플레이어 쪽으로 직선 띄 데칼이 얇게 깔리고 안쪽부터 붉게 참 |
| Startup · 정적 | 0.5s | **선율이 뚝 끊긴다.** 소리가 완전히 사라지고 술대만 높이 들린 채 정지. 데칼이 플레이어를 따라 회전하다 확정 |
| Active · 1타 | 0.15s | 6현을 한 번에 내려긁음. **"켾"** 파열음과 함께 핏빛 반달 참격이 튜어나가 직선으로 날아간다 |
| (간격) | 0.35s | 데칼이 **다시 플레이어 쪽으로 회전** — 재조준 예고 |
| Active · 2타 | 0.15s | 재조준된 방향으로 두 번째 참격 |
| (간격) | 0.50s | 데칼 재조준. **앞 간격보다 길다** — 반 박자 늦추는 뜼 |
| Active · 3타 | 0.20s | 이펙트 3겹의 마지막 참격. 데칼이 플레이어가 **달려가는 방향을 앞질러** 확정된다 |
| Recovery | 1.4s | 현 하나가 실제로 끊어져 늘어짐. 술대를 내리고 숨 고름 — **전투 중 최대 딜 구간** |

### 판정

- 형태: 직선 투사체. 반달 참격이 전방으로 전진하다 첫 명중에서 소멸한다 (관통 없음)
- 속도 / 사거리: 2100 / 1200
- 데미지: 1·2타 30 / 3타 55
- 재조준: 1타는 정적 동안 확정, **2·3타는 발동 직전 방향 재계산**
- 예측 조준: **3타만 현재 위치가 아니라 참격이 도달할 시점의 위치를 노린다.** 앞서 조준하는 비율은 0.7 (1.0은 회피 불가)
- 발사 간격: 1→2타 0.5s / **2→3타 0.65s.** 마지막만 벌려 방향을 바꿀 틈을 준다

### 설계 의도

예고가 "무언가 나타남"이 아니라 **"있던 것이 사라짐"**이다. 소리를 잃은 순간에 반응해야 한다. 서 있으면 재조준 때문에 2·3타를 반드시 맞으므로, 첫 타를 피한 뒤에도 계속 움직여야 한다.

**앞 두 발과 마지막 발이 다른 문제를 낸다.** 1·2타는 현재 위치 조준이라 옆걸음으로 흘려진다. 여기서 익힌 리듬을 3타가 배신한다 — 같은 방향으로 계속 달리면 예측 조준에 정통으로 들어간다. **방향을 꿗거나, 멈추거나, 대시해야** 피해진다.

- **회피**: 측면 회피 (3회)
- **텔레그래프**: 청각 — 소리의 **부재** + 직선 데칼
- **시간 성격**: 순간 판정 3연

## 5. 실음 (失音) — 급강하

`UBossAttack_DiscordDive`

> 상공으로 사라졌다가, 틀린 음 하나만으로 예고한다.

### 타임라인

| 상태 | 시간 | 연출 |
| --- | --- | --- |
| Startup · 연주 | 0.5s | 높은 음역으로 **떠오르듯 올라가는 3음** |
| Startup · 박쥐 소집 | 0.6s | 사방에서 박쥐 떼가 날아와 보스에 달라붙는다. 연주는 끊기지 않고 이어짐 |
| Startup · 상승 | 0.7s | 박쥐 떼에 실려 상공으로. 검은 안개가 뒤따른다 |
| Startup · 체공 | 1.2s | 카메라 밖 높이라 **보스가 보이지 않는다.** 멀어진 만큼 연주가 **웅웅거리며 뭉개짐.** 화면에 마커 없음 |
| Active · 틀린 음 | 0.4s | 뭉개진 선율 중 **음 하나가 명확히 어긋난다.** 유일한 예고 |
| Active · 착지 | 0.2s | 박쥐 떼가 흩어지며 급강하 착지. 지면 균열 데칼 + 카메라 셰이크 |
| Active · 흡혈 | - | 히트 시 붉은 입자가 플레이어에게서 보스로 빨려 들어가고 체력 회복. HUD에 회복량 표시 |
| Recovery | 1.5s | 웅크렸다 천천히 일어남. **빗나갔을 경우 술대를 놓쳐 딜 구간이 0.6s 연장** |

### 판정

- 형태: 착지 지점 중심 **내부 원 + 외곽 링** 2단
- 데미지: 내부 원 100 / 외곽 링 40 + 넉백
- 흡혈: 가한 피해의 50%를 보스 체력으로 회복

### 설계 의도

**네 공격 중 유일하게 시각 정보가 전혀 없다.** 보스가 안 보이고 마커도 없어 오직 소리로만 판단한다. 단현의 "정적"과 같은 청각 계열이지만, 단현은 **소리의 부재**, 실음은 **소리의 오류**로 성격이 정반대다.

회피 실패가 보스 체력 회복으로 이어져 압박이 수치로 드러난다.

- **회피**: 이격 회피
- **텔레그래프**: 청각 — 소리의 **오류** (보스는 시야 밖)
- **시간 성격**: 순간 판정 단발

## 6. 공명 (共鳴) — 확산 음파

`UBossAttack_ResonantWave`

> 거문고 6대를 세우고, 확장하는 음파 링으로 플레이어를 계속 달리게 만든다.

### 타임라인

| 상태 | 시간 | 연출 |
| --- | --- | --- |
| Startup · 연주 | 0.4s | 술대로 현을 훑어 내림. **낮게 깔리는 지속음** |
| Startup · 배치 | 1.2s | 그 소리를 따라 **거문고 6대가 반경 350 원주에 솟아올라** 세워짐. 6대의 현이 **술대 없이 동시에 떨기 시작.** 저주파가 커지며 화면 가장자리가 미세하게 흔들리고 지면 먼지가 떠오름 |
| Active · 1파 | 1.2s | 음파 링이 **반경 700**까지 확장. 공기 일렁임 + 원형으로 밀려나는 먼지 + 붉은 기운 |
| Active · 2파 | 1.2s | **반경 1100**까지. 같은 시간에 더 멀리 가므로 더 빠르다 |
| Active · 3파 | 1.2s | **반경 1500.** 가장 빠르고 판정이 두꺼움 |
| Recovery | 1.8s | 거문고 6대가 부서져 흩어지고 중앙의 보스는 무방비. 다만 플레이어는 경계까지 밀려나 있어 거리를 다시 좁혀야 함 |

Active 총 4.0s. 확산 시간은 같고 닿는 거리만 넓어진다.

### 판정

- 형태: **확장하는 링(도넛)** — 안쪽은 이미 지나가서 안전, **링 자체만 판정**
- 시작 반경: 보스가 아니라 **거문고가 늘어선 원(350)**에서 출발한다. 그 안쪽은 판정이 없다
- 데미지: 파당 25 + 출혈 지속 피해
- 피격 효과: **넉다운** (넘어지며 출혈)
- 최대 반경: 마지막 파가 아레나 경계 직전까지 닿는다
- 피격 횟수: 파당 1회. 같은 파에 연속으로 맞지 않는다

### 연출과 판정의 분리

음파는 잔상 때문에 **원판처럼 보여도 된다.** 다만 데미지는 언제나 **링만** 준다.

플레이어는 링의 **선단(바깥 경계)**을 보고 회피를 판단한다. 잔상이 두꺽고 밝으면 이미 지나간 자리를 위험하다고 오독해, 안전한데도 계속 도망치거나 반대로 선단을 놓친다.

- 선단: 뚜렷하고 밝게. 판정 위치와 정확히 일치시킨다
- 잔상: 빠르게 흐려지게. 안쪽이 안전하다는 것이 읽혀야 한다

### 설계 의도

회피가 "한 번의 판단"이 아니라 **4초 내내 계속 달리는 것**이다. 네 공격 중 유일한 지속 압박이며, 판정도 점·선·투사체가 아닌 **확장하는 링**이라 다른 셋과 겹치지 않는다. 파가 점점 멀리 퍼지므로 초반에 게으르면 후반에 닿는다.

넘어져 있는 동안 다음 파가 도착하면 연쇄로 맞는다 — 이 공격의 진짜 위험은 첫 피격이 아니라 그 뒤다.

### 밸런스 주의

**넉다운 후 기상 시 짧은 무적을 반드시 넣는다.** 없으면 한 번 넘어진 순간 남은 파를 전부 맞고 즉사하는 무한 연쇄가 된다.

- **회피**: 지속 도주 (중심에서 멀어지기)
- **텔레그래프**: 공간 — 링 확산 + 저주파 진동
- **시간 성격**: 지속 5초

## 7. 혈우 (血雨) — 폭주 2단 광역 [궁극기]

`UBossAttack_BloodRain`

> 폭주 후 지면과 하늘 양쪽에서 몰아친다. 전투의 분기점.

### 타임라인

| 상태 | 시간 | 연출 |
| --- | --- | --- |
| Startup · 폭주 | 2.0s | **핏빛 원이 보스를 삼킨다.** 원이 사라지면 **팔이 길어지고 손가락이 갈라진 기괴한 형상.** **양팔을 뒤로 젖히며 괴성.** 거문고에 핏줄이 돋고 **현이 12줄로 늘어남.** 이 동안 보스는 무적 |
| (연주) | 지속 | 여기서부터 정악이 아니라 **굉음의 난타.** 술대가 현을 마구 두들기는 불협화음이 궁극기 내내 이어짐 |
| Startup · 균열 | 1.0s | 바닥 여러 곳이 **쩍쩍 갈라지며 균열 예고선**이 뻗어나감. **갈라지는 순서 = 터질 순서** |
| Active 1단 · 지면 | 2.0s | 균열에서 **핏줄기가 순차적으로 솟구침.** 플레이어는 **균열 사이 틈에 자리를 잡아야** 한다 — 달리는 게 아니라 **읽고 서는** 회피 |
| 전환 | 0.5s | 솟구침이 멎고 균열이 닫힘. 보스가 술대를 머리 위로 치켜듦 |
| Active 2단 · 공중 | 4.0s | 하늘에서 **핏빛 줄기 수십 개가 우르르 비처럼 쏟아짐.** 바닥에 작은 낙하 그림자가 먼저 깔리고 그 자리에 떨어짐. 여기선 **계속 달려야** 한다 — 회피 축이 뒤집힘 |
| (강타) | - | 보스가 **현을 크게 튕길 때마다** 굵은 줄기 하나가 **대형 낙하.** 그림자도 크고 데미지도 큼. **불협화음 사이의 큰 한 음이 예고**라 소리로 미리 안다 |
| Recovery | 2.5s | 보스가 무릎을 꿇고 헐떡임. 거문고를 짚고 버팀 — **전투 중 가장 긴 딜 구간** |

### 판정

- 1단: 지면 균열 **라인** 판정, 데미지 45
- 2단 일반 낙하: 소형 원형, 데미지 30
- 2단 대형 낙하: 대형 원형, 데미지 80 + 넉백

### 폭주 유지 규칙

**첫 시전 때만 변신 연출을 재생하고, 이후 형상은 영구 유지한다.** 재시전 시엔 변신을 건너뛰고 바로 균열 단계부터 들어간다. 매번 2초짜리 변신을 다시 보면 늘어지고, 폭주한 외형이 유지돼야 페이즈가 바뀐 것이 체감된다.

### 기본기 강화

폭주 이후 기본 3개는 파라미터만 바꾼 강화판으로 교체된다.

| 스킬 | 강화 내용 |
| --- | --- |
| 단현 | 참격 3연 → **5연** |
| 실음 | 착지 후 **소규모 혈우**가 뒤따름 |
| 공명 | 거문고 **12대**, **4파**, 이중 회전 |

새 클래스를 만들지 않고 **어택 풀 DataTable에 페이즈별 행을 추가**하는 것만으로 구현한다. 코드 중복 없이 난이도 곡선이 생긴다.

- **회피**: 정지(틈에 서기) → 도주(그림자 피하기), 2단 전환
- **텔레그래프**: 시각 — 균열선 · 낙하 그림자 + 청각 — 큰 한 음 = 대형 낙하
- **시간 성격**: 지속 8초 (궁극기)

| **단현** | 측면 회피 ×3 | 직선 투사체 3연 | 청각 — 소리의 **부재** | 순간 판정 3연 |
| **실음** | 이격 회피 | 원형 + 외곽 링 | 청각 — 소리의 **오류** | 순간 판정 단발 |
| **공명** | 지속 도주 (바깥으로) | **확장하는 링** | 공간 — 확산 + 진동 | 지속 4초 |
| **혈우** | **정지 → 도주** (2단) | 지면 균열 + 공중 낙하 | 시각 — 균열선 · 그림자 | 지속 8초 |

- 단현과 실음은 둘 다 청각이지만 **부재 vs 오류**로 갈리고, 실음은 시야를 아예 차단해 청각 의존을 강제한다.
- 공명과 혈우는 둘 다 "달린다"지만, **공명은 방향이 정해진 도주**(중심에서 멀어지기)이고 **혈우 2단은 무작위 그림자 회피**다. 혈우는 앞 절반이 "달리면 안 되는" 정지 회피라 체감이 반대다.
- 거리대도 갈린다: 근접(단현) / 중거리 이상에서 유발(실음) / 전 범위(공명·혈우).

## 9. 페이즈 구성

| 페이즈 | 사용 공격 |
| --- | --- |
| 1 | 단현, 실음 |
| 2 | 단현, 실음, 공명 |
| 3 | 혈우로 진입 → 이후 강화판 단현 · 실음 · 공명 + 혈우 재사용 |

어택 풀 DataTable(`FBossAttackPoolRow`)에 (공격 × 페이즈) 조합으로 행을 두고 가중치·쿨다운·거리 조건을 설정한다.

## 10. 구현 순서

1. **단현** — 직선 투사체 판정 + 재조준. 상태 머신과 텔레그래프의 기준이 되므로 먼저 만든다
2. **실음** — 기존 `ShadowCrash`의 상승·급강하 흐름을 재사용, 시야 차단과 흡혈을 추가
3. **공명** — 확장 링 판정을 새로 작성. 넉다운·출혈과 기상 무적 처리 포함
4. **혈우** — 앞 셋의 판정 요소를 조합. 2단 전환과 연주 리듬 동기화가 핵심
5. **DataTable 페이즈별 행 추가** — 강화판 파라미터 구성
